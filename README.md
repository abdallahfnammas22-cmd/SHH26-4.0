# مغامرة الفلزات القلوية والأرضية

موقع/لعبة تعليمية عربية بسيطة تعمل مباشرة في المتصفح.

## الملفات
- `index.html`
- `style.css`
- `script.js`
- `.nojekyll`

## النشر على GitHub Pages
1. ارفع **كل الملفات الأربعة** إلى الصفحة الرئيسية (root) للمستودع.
2. افتح Settings > Pages.
3. اختر Deploy from a branch.
4. اختر `main` ثم `/ (root)`.
5. اضغط Save.
